## 三、核心代码与功能说明
### 1. BMI 计算器：多分支条件判断
**文件名称：** `BMI（互动+条件）.py`
**程序功能：**
用户输入自己的体重（kg）和身高（m），程序自动计算 BMI 指数，并根据计算结果判断体重分类，输出相应的提示信息。
**核心计算公式：**
BMI = 体重（kg）÷ 身高（m）²
**核心代码说明：**
- `input()`：接收用户输入的身高和体重。
- `float()`：将输入的字符串转换为浮点数，以便进行数值计算。
- 算术运算：通过 `**2` 计算身高的平方，再计算 BMI 指数。
- `if-elif-else`：根据 BMI 数值进行多分支判断，实现不同区间的分类。
- 连续比较：使用 `18.5 <= user_BMI <= 25` 等写法简化区间判断。
**程序分类逻辑：**
| BMI 数值范围 | 程序输出分类 |
|---|---|
| BMI < 18.5 | 消瘦 |
| 18.5 ≤ BMI ≤ 25 | 正常 |
| 25 < BMI ≤ 30 | 偏胖 |
| BMI > 30 | 肥胖 |
**输入注意事项：**
- BMI 计算器要求体重以 kg 为单位、身高以 m 为单位，输入数值必须能够转换为浮点数。

### 2. 平均值计算器：while 条件循环
**文件名称：** `求平均值小程序（循环）.py`
**程序功能：**
用户可以连续输入多个数字，程序通过 `while` 循环不断接收数据。当所有数字输入完成后，输入小写字母 `q` 结束程序，最终计算并输出所有已输入数字的平均值。
**核心计算公式：**
平均值 = 所有数字之和 ÷ 数字总个数
**核心代码说明：**
- `total = 0`：初始化累加器，用于记录所有输入数字的总和。
- `count = 0`：初始化计数器，用于记录输入数字的个数。
- `while user_input != 'q'`：设置循环条件，当用户输入 `q` 时结束循环。
- `total += number`：将每次输入的数字累加到总和中。
- `count += 1`：每接收一个数字，计数器增加 1。
- `if count == 0`：判断用户是否输入过数字，避免出现除以零的情况。
- `result = total / count`：计算并输出平均值。
**输入注意事项：**
- 平均值计算器支持整数和小数输入，输入结束时需要使用小写字母 `q` 退出。
