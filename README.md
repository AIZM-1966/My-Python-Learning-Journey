## 1. BMI计算器 | if-elif-else多分支条件判断
### 核心知识点
- 多分支 if-elif-else：从上至下顺序判断，匹配成功即退出分支，适合互斥分类场景。
- Python连续比较语法 `a <= x <= b`，简化区间判断。
- 输入类型转换：`float()` 将输入字符串转为数值，才可进行大小比较。

## 2. 平均值计算器 | `while` 条件循环
### 核心知识点
- `while` 条件循环：先判断条件，条件为真才执行循环体；适合未知循环次数场景。
- 哨兵终止：设定标记 `q` 作为退出信号。
- 累加器 `total`、计数器 `count`：必须在循环外初始化，循环体内持续更新。
- 边界防护：判断 `count == 0`，避免除零异常。
